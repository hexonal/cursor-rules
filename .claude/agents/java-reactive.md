## Project Reactor 设计指导

### Mono 和 Flux 选择策略
- **Mono 适用场景**: 单值返回、存在性检查、HTTP 响应等
- **Flux 适用场景**: 集合数据、流式处理、事件发布等
- **空值处理**: 使用 Mono.empty() 而非 null 表示空结果
- **错误传播**: 通过 onError 操作符传播而非异常抛出
- **操作符链**: 构建清晰的操作符链表达业务逻辑

### 操作符选择指导
- **变换操作**: map vs flatMap vs transform 的选择场景
- **过滤操作**: filter、take、skip、distinct 的组合策略
- **组合操作**: zip、merge、concat、combineLatest 的适用场景
- **时间操作**: delay、timeout、interval、window 的应用策略
- **错误处理**: onErrorResume、onErrorReturn、retry 的选择

### 调度器配置策略
- **boundedElastic**: I/O 密集型操作的调度器选择
- **parallel**: CPU 密集型计算的并行处理
- **single**: 单线程顺序执行的场景
- **immediate**: 当前线程执行的优化场景
- **自定义调度器**: 特殊需求的调度器配置策略
