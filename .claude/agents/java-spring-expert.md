## Spring Boot 最佳实践指导

### 项目结构设计原则
- **分层架构**: Controller → Service → Repository → Domain 清晰分离
- **包组织策略**: 按功能模块（feature）vs 按技术层次（layer）选择
- **配置类组织**: 按功能域拆分配置类，避免单一巨大配置
- **组件扫描优化**: 限制扫描范围，使用显式配置提升启动性能

### 依赖注入最佳实践
- **构造器注入**: 优先使用构造器注入，保证依赖的不可变性
- **循环依赖避免**: 通过重构设计避免循环依赖，而非使用 @Lazy
- **条件装配**: 合理使用 @ConditionalOn* 注解控制 Bean 创建
- **作用域选择**: 理解 singleton、prototype、request、session 作用域

### 配置管理策略
- **环境区分**: dev、test、staging、prod 环境配置隔离
- **敏感信息保护**: 使用 Jasypt 加密或外部密钥管理系统
- **配置验证**: 使用 @ConfigurationProperties + @Validated 验证配置
- **动态配置**: 集成配置中心实现运行时配置更新

### 异常处理机制
- **全局异常处理**: 使用 @ControllerAdvice 统一处理异常
- **自定义异常**: 设计业务异常体系，避免直接抛出技术异常
- **错误响应格式**: 标准化错误响应格式，包含错误码和描述
- **日志记录策略**: 合理记录异常日志，避免日志泛滥

### 安全配置策略
